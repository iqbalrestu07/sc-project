# Immersive 3D Interactive Landing Page

> Dokumentasi implementasi 3D landing page untuk Shasi Beauty Care.
> Dibuat: 2026-07-30. Stack: Three.js + React Three Fiber + drei + Framer Motion.

---

## 0. Mode 3D Landing Page

Landing page support 3 mode yang dipilih via env variable `VITE_LANDING_MODE`:

| Mode     | Deskripsi                                             | Kapan dipakai                        |
| -------- | ----------------------------------------------------- | ------------------------------------ |
| `2d`     | Orbit-only 3D di Hero (default, ringan)               | Default — tanpa model GLB            |
| `hero3d` | 3D full di Hero section (crystal + orbit + particles) | Device standar, mau tampilan lengkap |
| `full3d` | Single canvas scroll-journey untuk semua section      | Device powerful, pengalaman imersif  |

**Cara set mode:**

```bash
# Di shasi/.env
VITE_LANDING_MODE="full3d"   # atau "hero3d" atau "2d"
```

**Auto-fallback:** Jika device tidak support 3D (WebGL, CPU, RAM), mode otomatis turun ke `2d` terlepas dari config. Lihat `useDeviceCapability` hook.

### Arsitektur per mode

**hero3d mode:**

- HeroSection render Hero3DScene internal (canvas di dalam hero)
- Section lain pakai TiltCard (pseudo-3D CSS)

**full3d mode:**

- Full3DScene render single canvas `position: fixed` di belakang semua section
- Kamera bergerak melalui 4 stage 3D seiring scroll:
  - Stage 0 (0-15%): Hero — kristal + particles
  - Stage 1 (15-35%): Services — 3D floating cards interaktif
  - Stage 2 (35-55%): Gallery — 3D picture frames
  - Stage 3 (55-75%): Promotions — 3D floating banners
- HTML content scroll di atas dengan `z-10`
- HeroSection skip 3D internal (Full3DScene sudah jadi background)

**2d mode:**

- Jika device support 3D: Hero3DScene tetap render tetapi **orbit-only** — orbiting crystals + particles tetap ada, kristal utama (CrystalSpinnerModel GLB) di-skip untuk hemat bundle
- Jika device lemah (auto-fallback): tidak ada canvas 3D sama sekali, HeroSection pakai parallax CSS + StarField
- Section lain tetap pakai TiltCard

| Layer            | Teknologi                         | Section                       | Bundle                                          |
| ---------------- | --------------------------------- | ----------------------------- | ----------------------------------------------- |
| Full 3D (hero3d) | Three.js + R3F + drei             | Hero scene                    | Lazy chunk (~2 KB wrapper + shared model chunk) |

## 3. Cara Mengubah 3D Model

Saat ini Hero scene memakai model **Crystal Spinner** dari Sketchfab (terkompresi 150KB → 20KB).

### Mengganti dengan model lain

#### Step 1: Download model

- Download model dari [Sketchfab](https://sketchfab.com) (pilih lisensi gratis, format `.glb`)
- Atau buat sendiri di Blender, export sebagai `.glb`
- Taruh file di `shasi/public/models/`

#### Step 2: Optimasi & generate component (pakai Makefile)

```bash
make model-transform MODEL=nama-model.glb
```

Makefile akan otomatis:

1. Kompresi model (Draco + texture resize + WebP) → `nama-model-transformed.glb`
2. Generate React component → `shasi/src/components/nama-model.tsx`
3. Pindahkan file ke `shasi/public/models/`

#### Step 3: Update Hero3DScene.tsx

Ganti import dan komponen `Crystal`:

```tsx
import { Model as NewModel } from "@/components/nama-model";

function Crystal() {
  return (
    <Float speed={1.5} rotationIntensity={0.4} floatIntensity={1.2}>
      <group ref={groupRef} scale={3.5}>
        <NewModel />
      </group>
    </Float>
  );
}
```

#### Step 4: Verifikasi

```bash
make fe-build
```

### Makefile commands untuk 3D models

| Command                               | Fungsi                                             |
| ------------------------------------- | -------------------------------------------------- |
| `make model-transform MODEL=nama.glb` | Kompresi + generate React component                |
| `make model-list`                     | List semua file 3D model di `shasi/public/models/` |
| `make model-clean MODEL=nama.glb`     | Hapus file transformed untuk model tertentu        |
| `make model-clean`                    | Hapus SEMUA file transformed + component           |

## 4. Tentang `gltfjsx --transform`

### Apa itu gltfjsx?

Tool CLI dari ekosistem `@react-three/drei` yang mengubah file `.glb`/`.gltf` menjadi React component.

### Apa yang dilakukan `--transform`?

Flag `--transform` menjalankan [glTF-Transform](https://github.com/donmccurdy/glTF-Transform) untuk optimasi model:

| Optimasi          | Efek                                                 |
| ----------------- | ---------------------------------------------------- |
| Draco compression | Kompresi geometri — **70-90% size reduction**        |
| Texture resize    | Resize texture ke 1024x1024 (default)                |
| Texture format    | Convert ke WebP (lebih kecil dari PNG/JPG)           |
| Prune             | Hapus empty groups, unnecessary transforms           |
| Dedupe            | Hilangkan material/geometry duplikat                 |
| Mesh join         | Gabung mesh compatible untuk draw call lebih sedikit |

### Apakah kita membutuhkannya?

**Ya, sangat recommended** saat Anda mulai pakai model GLB asli (bukan procedural). Alasan:

1. **Ukuran file** — model Sketchfab biasanya 5-20MB. Setelah `--transform` bisa turun ke 500KB-2MB.
2. **Performa** — fewer draw calls, pruned nodes = render lebih cepat.
3. **Type safety** — `--types` generate TypeScript definitions, jadi Anda bisa akses node model dengan autocomplete.
4. **Reusability** — model jadi React component, bisa dipakai ulang & dimanipulasi props.

### Kapan TIDAK perlu?

- Saat masih pakai kristal procedural (sekarang) — tidak ada file GLB yang perlu di-process.
- Jika model sudah dioptimasi manual di Blender sebelum export.

### Command lengkap yang recommended

```bash
npx gltfjsx public/models/nama-model.glb --transform --types --shadows
```

| Flag          | Fungsi                                         |
| ------------- | ---------------------------------------------- |
| `--transform` | Kompresi Draco + texture resize + webp + prune |
| `--types`     | Generate TypeScript definitions                |
| `--shadows`   | Enable cast/receive shadows pada mesh          |

## 5. Device Detection & Fallback

`useDeviceCapability` hook menentukan apakah device bisa render 3D:

```typescript
const { supports3D, isMobile, prefersReducedMotion } = useDeviceCapability();
```

**3D di-disable jika salah satu kondisi terpenuhi:**

- User set `prefers-reduced-motion` (accessibility)
- Browser tidak support WebGL
- `navigator.hardwareConcurrency` < 4 (CPU lemah)
- Mobile + `navigator.deviceMemory` < 4 GB (RAM kecil)

Saat 3D disabled, Hero otomatis fallback ke versi 2D (background image + parallax CSS yang sudah ada).

## 6. Customization

### Mengubah warna kristal

Edit `Hero3DScene.tsx` di bagian design tokens:

```tsx
const GOLD = "#C9A84C"; // warna utama kristal
const GOLD_LIGHT = "#E8C870"; // warna orbiting crystals
const MAROON_DARK = "#3D0610"; // emissive + fog
```

### Mengubah kecepatan rotasi

```tsx
// Crystal auto-rotation
meshRef.current.rotation.y += 0.003; // ubah nilai ini

// Orbiting crystals
groupRef.current.rotation.y += delta * 0.15; // ubah nilai ini
```

### Mengubah jumlah particle

```tsx
<Sparkles count={120} ... />  // ubah count
<Sparkles count={60} ... />   // ubah count
```

### Mengubah tilt sensitivity (TiltCard)

```tsx
<TiltCard maxTilt={10} hoverScale={1.03}>  // ubah maxTilt & hoverScale
```

## 8. Troubleshooting

### Build error: peer dependency conflict

```bash
npm error peer react@">=19 <19.3" from @react-three/fiber
```

**Solusi:** Install versi v8 untuk React 18:

```bash
npm install three @react-three/fiber@^8.17.10 @react-three/drei@^9.114.0
```

### 3D scene tidak muncul

1. Cek `useDeviceCapability` — mungkin device terdeteksi lemah
2. Buka DevTools Console — cek error WebGL
3. Cek `prefers-reduced-motion` di OS settings

### Model GLB tidak load

1. Pastikan file ada di `shasi/public/models/`
2. Pastikan path di `useGLTF('/models/nama.glb')` benar (absolute path dari public)
3. Jika pakai Draco compression, pastikan `--transform` sudah dijalankan

### Bundle size terlalu besar

1. Pastikan `Hero3DScene` di `lazy()` import (bukan direct import)
2. Jalankan `npx gltfjsx --transform` untuk kompresi model
3. Cek ukuran file GLB — idealnya < 2MB setelah transform
